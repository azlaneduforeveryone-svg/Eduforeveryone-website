3. MUTATION TESTING LIMITATION
No valid mutation test exists for this classifier design. The classifier evaluates
only the explanation text (which is static). Mutating a stored index in memory does
not alter the explanation text, making automated mutation testing a tautology rather
than an empirical measurement.

This check is retained strictly as a regression guard on future edits to existing
classifiable items, not as an automated bug discovery tool.
